# RF01 - Registro de activos

## Descripción

SENASTOCK permitirá registrar activos del inventario institucional.

## Información del activo

El sistema permitirá almacenar información como:

- Código.
- Descripción.
- Tipo.
- Estado.
- Ubicación.

## Módulo relacionado

Módulo de Registro de Activos.

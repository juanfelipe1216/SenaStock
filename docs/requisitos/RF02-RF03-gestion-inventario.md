# RF02 y RF03 - Gestión del inventario

## RF02 - Consulta y filtrado de inventario

SENASTOCK permitirá consultar los activos registrados
en el inventario institucional.

El usuario podrá realizar búsquedas utilizando criterios como:

- Tipo de activo.
- Estado.
- Ubicación.

## RF03 - Actualización y eliminación de activos

SENASTOCK permitirá actualizar la información de los
activos registrados cuando existan cambios.

También permitirá dar de baja o eliminar registros
cuando corresponda según las reglas del sistema.
